# DESIGN.md — 瓦电赛事运营中台 功能介绍 PPT

## 风格定位
通用设计原则（项目介绍 / 工作总结场景）。调性：科技电竞 · 暗色冷峻 · 数据驱动 · 克制专业。
呼应 Valorant 红蓝品牌调性，但仅作点缀，不喧宾夺主。

## 1. 画布与母版（默认三区）
- 画布：1280×720
- A 标题块：0–120px，主标题 34px bold，左侧 60px padding 起
- B 内容区：120–660px，540px 可用
- C 页脚条：660–720px，左项目名「瓦电赛事运营中台」+ 右页码 `NN / 18`，14px 灰字
- 页面 padding：上下 20px、左右 64px
- 封面/章节扉页/结束页允许自定义版式（省略 C 区页码或改用底部居中）

## 2. 颜色系统（对齐中台实际用色 style.css）
中台真实主题：`--bg:#120A0B │ --panel:#1A0D0E │ --panel2:#241215 │ --line:#331A1D │ --txt:#F0E8E8 │ --sub:#B0A0A0 │ --dim:#7B7F7D │ --accent:#DC3030 │ --accent2:#FD2659 │ --ok:#49FFD3`。

| 角色 | HEX | 用途 |
| :--- | :--- | :--- |
| 背景主色 | `#120A0B` | 深红黑底，全篇主背景（对应 --bg） |
| 面板/卡片底 | `#1A0D0E` / `#241215` | 卡片、面板、SVG 图形填充（对应 --panel / --panel2） |
| 分隔线 | `#331A1D` | 边框、卡片描边、页脚线（对应 --line） |
| 主色（中台红） | `#DC3030` | 标题栏、卡片头、结构线、主图标（对应 --accent） |
| 辅色（品红） | `#FD2659` | 第二系列、流程节点、强调点缀（对应 --accent2） |
| 成功/强调绿 | `#49FFD3` | 状态点、正向标注（对应 --ok） |
| 文本主色 | `#F0E8E8` | 正文浅暖白（对应 --txt） |
| 次要文本 | `#B0A0A0` | 说明、副标题（对应 --sub） |
| 中性灰 | `#7B7F7D` | 页脚、最弱文字（对应 --dim） |

### 2.1 色彩面积分配
- 背景（深红黑）≤ 60%（实为背景主体）
- 主色（红 #DC3030）/ 面板 ≤ 30%（卡片背景、结构、图标）
- 辅色（品红 #FD2659）≤ 15%（流程节点、关键标注）；Hero 页可达 18-22%
- 成功绿（#49FFD3）仅作状态点缀 ≤ 5%
- 中性灰为文本与边框

### 2.2 渐变与半透明
- 标题栏/章节背景：`linear-gradient(135deg, #120A0B 0%, #241215 100%)`
- 卡片：`background: rgba(220,48,48,0.08)` + `boxShadow: 0 4px 20px rgba(0,0,0,0.4)`
- 主红可叠 `rgba(220,48,48,0.12)` 浅色块；品红 `rgba(253,38,89,0.12)`

## 3. 字体系统
- 标题：思源黑体 / Noto Sans SC（bold），字重 700-900
- 正文：思源黑体 / Noto Sans SC（regular），字重 400
- 巨型数字/锚点：同族 bold，与正文形成尺度跳跃（≥ 72px）
- 西文/数字搭配：Inter / Helvetica Neue
- 禁止全篇仅系统默认无衬线

### 字号层级
| 层级 | 字号 | 字重 |
| :--- | :--- | :--- |
| 封面主标题 | 64px | 800 |
| 章节大字 | 60px | 800 |
| 巨型数据/锚点 | 72–110px | 800 |
| 页面主标题 | 34px | 700 |
| 卡片小标题 | 24px | 600 |
| 正文 | 22px | 400 |
| 脚注/页码 | 14px | 400 |

## 4. 信息密度门禁
- 内容页：字数 ≥ 180，主视觉占 B 区 ≥ 30%
- 卡片填充率 ≥ 85%，尾部元素 marginBottom 钉底
- 常规页留白 ≤ 35%；封面/章节/结束页不受限
- 焦点元素周围留白 ≥ 40px

## 5. 配图系统
- 本 deck 以 SVG 结构化图为主（架构图/时间轴/数据分层/流程图），符合"流程图、架构图、时间轴可用 SVG"规则。
- 封面/章节/结束页用 CSS 渐变背景 + 几何色块营造电竞氛围，不强行生图（避免写实摄影与数据主题割裂）。
- 无 L1 写实摄影主视觉；L3 角标：右下页码 + 左上项目名，全篇一致。
